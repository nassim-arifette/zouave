# Zouave · 2-minute pitch video

Latest render: [`zouave-pitch.mp4`](zouave-pitch.mp4) (v3, 1 min 53 s). Earlier versions: [`versions/`](versions) — v1 (app screenshots only), v2 (+ Google Photorealistic 3D and the street going under water).

[HyperFrames](https://hyperframes.heygen.com) composition (HTML + GSAP, rendered to MP4) built from real screenshots of
the app and the Zouave's voice (ElevenLabs v3, "Jamie", French accent), with burned-in subtitles.
Scene by scene script: [`docs/PITCH.md`](../docs/PITCH.md).

| File | Role |
| --- | --- |
| `index.html` | The composition (generated by `build.py`, do not edit by hand) |
| `build.py` | Builds `index.html` from the voice-over lines, their real durations and word timings |
| `capture.mjs` | Takes the app screenshots (`assets/shots/`) by running Story mode and one chat question |
| `assets/vo/lines.json` | The voice-over script, with ElevenLabs v3 audio tags (`[excited]`…); subtitles strip them |
| `assets/vo/*.mp3` | Voice-over, one file per scene · `*.words.json`: word timings (ElevenLabs speech-to-text) |
| `assets/shots/*.jpg` | App screenshots, 1920×1080 |
| `assets/img/g-*.jpg` | Google Photorealistic 3D views from `docs/google-compare/` (`scripts/compare-google.mjs`); the aerial ones are cropped below the HUD, and the Google attribution is drawn on the frame |
| `assets/img/z-*.webp` | The Zouave presenter: still and open-mouth frames (lip-sync on the word timings) and the OpenAI poses from `web/public/zouave/living-stone/` |
| `assets/img/street-*.jpg` | The demo street dry, at 0.5 m and at 1.5 m: OpenAI image edits of a Panoramax photo (Lejun, CC BY-SA 4.0), from `web/public/photos/4-rue-traversiere/` |

## Render

```sh
cd video
npx hyperframes render -o zouave-pitch.mp4 --quality delivery
```

## Rebuild after a change in the app

```sh
npm start                      # in another terminal
node video/capture.mjs         # writes assets/shots/*.png (CHROME_PATH=... if Playwright has no browser)
python3 video/build.py         # converts the shots to JPEG and regenerates index.html
cd video && npx hyperframes check && npx hyperframes render -o zouave-pitch.mp4 --quality delivery
```

`build.py` inserts a "This is not a simulation" scene (voice-over `05-memory`) when `assets/img/memory-1910.jpg`
exists: a real, public-domain photograph of the 1910 flood (see `npm run fetch-1910`).

Every figure on screen comes from the app or its sources: 8.62 m at Austerlitz (DRIEAT), up to 5 million people and
€30 billion ([OECD](https://www.oecd.org/fr/publications/mieux-prevenir-les-inondations-de-la-seine-en-ile-de-france_9789264290082-fr), the source Story mode links), 7,505 buildings (IGN BD TOPO
in the app's mapped area), 1 to 2 m at 4 rue Traversière (Paris PPRI).
